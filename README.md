# Chibik — экранный питомец Мира

Chibik — прозрачное окно с постоянным пиксельным домиком и персонажем Мирой. Старое окно Tkinter не используется. Приложение запускается на PySide6/QML.

## Запуск в Windows / PyCharm

Откройте корень проекта `Chibik-main` в PyCharm. В терминале PyCharm выполните:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

В PyCharm выберите интерпретатор `.venv\Scripts\python.exe`. Для запуска используйте `main.py` в корне проекта либо `app/main.py`.

## Возможности

- Постоянная сцена-домик на рабочем столе и отдельный PNG-скин Миры.
- Анимации ожидания, ходьбы, сна и стояния.
- Автономное перемещение по сетке с поиском пути A* и проверкой физики.
- Потребности персонажа: энергия, голод, веселье, общение, гигиена и комфорт.
- Контекстное меню, чат, настройки и речевое облако.
- Перетаскивание локального файла на Миру: приложение распознаёт файл и сообщает его имя/размер. **Оригинал не удаляется, не перемещается и не изменяется.**

## Дополнительные функции (по желанию)

Базовый запуск не требует OpenAI, Playwright или Whisper. Это предотвращает падение приложения из-за необязательных нативных зависимостей.

### Локальная LLM

Установите пакет:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-ai.txt
```

Запустите OpenAI-совместимый локальный сервер (например, LM Studio), затем создайте `.env` в корне проекта:

```env
CHIBIK_LLM=local
LOCAL_LLM_URL=http://127.0.0.1:8080/v1
LOCAL_LLM_MODEL=имя-модели-на-сервере
```

Если LLM не загрузится, Мира всё равно запустится в автономном режиме. Без `CHIBIK_LLM=local` используется автономный режим, даже если в `.env` остался `LOCAL_LLM_URL`.

### Браузерные инструменты

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-browser.txt
.\.venv\Scripts\python.exe -m playwright install chromium
```

### Голосовой ввод

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-voice.txt
```

При первом запуске Whisper может загрузить модель распознавания; потребуется интернет. Также нужен доступный микрофон и разрешение Windows.

## Устройство проекта

- `app/main.py` — запуск QGuiApplication и QML.
- `app/ui/qml/` — домик, персонаж, чат и панели.
- `app/ui/python/bridge.py` — связь QML с Python, чат, голос и безопасный приём файлов.
- `app/ui/python/desktop_world.py` — игровой цикл, движение, потребности и AI-агент.
- `app/world/` — мир, физика и навигация.
- `app/character/` — состояние, характер, память и поведение Миры.

## Ограничения текущей версии

- Для содержательного диалога нужна отдельно настроенная локальная LLM; автономный режим служит для проверки интерфейса и базовой работы.
- Голосовой ввод опционален; генерация речи (TTS) пока не подключена к интерфейсу.
- Перемещение учитывает границы сцены, но не определяет расположение значков рабочего стола Windows.

## Проверка проекта

Из корня проекта можно выполнить офлайн-тесты:

```powershell
.\.venv\Scripts\python.exe -m pip install pytest
.\.venv\Scripts\python.exe -m pytest -q
```

Тесты браузерных инструментов не открывают реальные сайты и не запускают браузер.


## Новые действия Миры

- Облачко реплики перемещается вместе с Мирой, пока она говорит.
- Пункт «Погулять» ведёт Миру к двери, после чего сцена переключается на пиксельный двор.
- Во дворе в контекстном меню доступен пункт «Домой» — Мира возвращается к двери и входит в комнату.
- Чтобы «покормить» Миру файлом, перетащите отдельный файл прямо на её спрайт. Файл перемещается в системную Корзину, а не удаляется навсегда; его можно восстановить. Папки не принимаются.

Для действия с файлами установлена зависимость `send2trash` из `requirements.txt`.

# Chibik — Desktop Pet

Chibik запускается как прозрачный безрамочный персонаж поверх рабочего стола Windows, а не как отдельное окно комнаты. Мира использует исходные PNG-кадры из `assets/characters/chibik/`, самостоятельно ходит по доступной области экрана, меняет направление и анимацию. Перетаскивание синхронизируется с моделью мира.

## Запуск

Требуется Python 3.13 или совместимая версия и Windows с графической сессией. В PowerShell из каталога проекта:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m playwright install chromium
.\.venv\Scripts\python.exe main.py
```

Окно питомца прозрачное, без рамки и закреплено поверх окон; оно содержит только персонажа. Щёлкни правой кнопкой по Мире, чтобы открыть меню. `Escape` закрывает приложение.

## Что связано в этой версии

- QML-анимация и PNG-скин Миры.
- Экранная область представлена как `World` / `Zone`; координаты персонажа хранятся в `WorldObject`.
- `Navigation` строит маршрут A*, `Physics` проверяет каждый шаг, а Qt-таймер обновляет позицию примерно 60 раз в секунду.
- Персонаж самостоятельно гуляет, меняет направление, расходует потребности и реагирует на низкие значения через `Behavior` / `Agent`.
- Чат обращается к `Agent` в фоновом потоке. Инструмент `desktop_walk` позволяет подключённой LLM попросить персонажа перейти в указанную клетку экрана.
- По умолчанию используется `MockLLM`, если локальная LLM не настроена. Если в `.env` задан `LOCAL_LLM_URL`, приложение выбирает `LocalLLM`; это OpenAI-совместимый локальный сервер (например, LM Studio). Для принудительного выбора задайте `CHIBIK_LLM=local` или `CHIBIK_LLM=mock`.

## Важно

- `main.py` — запуск экранного питомца. `python -m app.main` запускает отдельный экспериментальный Tkinter-прототип комнаты и не нужен для Desktop Pet.
- Движение происходит по свободной области экрана. Иконки рабочего стола не являются препятствиями для A*: Windows не предоставляет их координаты через текущую модель мира.
- Голосовые и веб-функции имеют дополнительные зависимости и могут требовать отдельной настройки.
